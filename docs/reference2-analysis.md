# 参考2.jpeg 多模态判读与实现建议

## 观察

`参考2.jpeg` 是 1600 × 1600 的 JPEG，内容是一张放在白色纸面上的 Risograph 风格静物印刷品：

- 外圈有很宽的白色纸边，真正印刷画面是竖构图；
- 画面内不止三种油墨：蓝、黄、橙、绿、粉、桃色、黑、白等多种颜色；
- 有细密网点和套印纹理，花朵、花瓶、水果、刀叉等主体边界清晰；
- 它是**平面印刷品照片**，不是深度图；灰度/明暗主要来自油墨和光照，不是真实高度。

## 为什么当前版本“还原不了”

当前管线是：

1. 三色图 → 提取三种 RGB；
2. 三色图 → 稀疏圆点阵（默认 1.6 mm 间距）；
3. 顶层负片 + 下两层圆柱；
4. 深度图或颜色派生的高度场。

对参考2会出现三个根本限制：

1. **颜色数不匹配**：参考2有 6–8 种油墨/纸色，压成三种 RGB 会丢掉大量颜色关系。
   当前提取结果是 `#e8e827 / #e489b7 / #3887c8`，已经能看出这种压缩。
2. **点阵间距过大**：当前默认 1.0 mm 点距仍只能表达点阵，不能连续还原色块，无法表达花蕊、水果切面、
   瓶身边缘等细节。
3. **深度不是扫描/渲染深度**：参考2是平面印刷品照片；用颜色角色映射生成高度
   只能得到几个大色块，不能产生花瓶、花朵、桌面的真实前后层次。

单纯把几何栅格从 0.20 mm 调到 0.10/0.05 mm 不会解决颜色数和网点表达问题；
0.05 mm 在 105 mm 画布上是 2100 × 2100 个单元，浏览器构建/发热也不现实。

## 建议的两条路线

### A. 三色网点分离（保持三件可打印）

适合继续做三色 FDM：

1. 自动裁出白色纸边，只保留印刷画面（或保留纸边作为顶层底板）。
2. 将多色图分解成三种目标油墨（例如蓝 / 黄 / 粉），使用：
   - 有序网点（Bayer）或误差扩散；
   - 或 AM 圆点/聚簇网点；
   - 每个网点只属于一种油墨或纸白，输出 0/1/2 索引图。
3. 网点间距降到约 0.5–0.8 mm；顶层颜色填充剩余空隙，形成顶层负片。
4. 三件支撑/圆柱仍按现有分层逻辑，但圆柱改为网点级、数量大幅增加。
5. 验收：索引图唯一值必须恰好是 0/1/2。

这条路能把参考2的构图和明暗关系保留下来，但不能保留 6–8 种原色；
它是“三色网点诠释”，不是像素级复刻。

### B. 全彩 / 多材料浮雕（不是三件）

如果目标是“尽量像参考2.jpeg”：

- 顶面使用原图 RGB 顶点色或纹理；
- 深度用单目深度模型（Depth Anything/MiDaS）或手工分层；
- 不再是三色 FDM 分件。

## 深度建议

参考2是平面印刷品：

- 若只想做浅浮雕：使用亮度作为高度（平滑设为 0 可保留边缘），
  这就是目前“深度图”路径能做的最直接近似；
- 若想做真实物体前后层次：需要单目深度估计或人工分层（纸面/桌面/花瓶/花/水果），
  不是当前“颜色角色 → 三个高度”的算法能完成的。

## 当前可以立即验证的

- 参考2作为 **COLOR / 三色** 输入：画布应变为 `105.0 × 105.0 mm`，
  栅格 `525 × 525`（0.20 mm），底部正方形。它是 1600 × 1600 的方形图。
- 参考2作为 **DEPTH** 输入：按当前约定不改变画布（画布只跟随三色图），
  但可以用“深度平滑 = 0”保留其灰度边缘。
- 当前三色提取对参考2得到 `#e8e827 / #e489b7 / #3887c8`，不是原图全部颜色。

**需要你确认目标**：优先做 A（三色网点分离，保持三件可打印），
还是先做 B（全彩/多材料浮雕，只追求像参考2）？
